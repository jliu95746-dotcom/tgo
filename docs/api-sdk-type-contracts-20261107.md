# API 存储与 IP 定位 SDK 契约校准（2026-11-07）

阶段：4.2.356。范围仍为 D1～D7、P1～P9、G0～G5；真实订单/物流暂缓，安卓取消。本批只完成 SDK 调用与工程检查的相关部分，不关闭整个业务类别。

## 实现与保留范围

- 修复 `py-ip2region 3.0.2` 的实际调用错误：`IPv4`、`IPv6` 已经是包含完整参数的 `Version` 对象，原来再次调用 `Version(version)` 会因缺少参数而加载失败。现在直接传入原对象，保留双库选择、查询解析、关闭和失败时空位置回退。
- 新增项目实际使用的 `ip2region`、`oss2` 类型声明；S3 使用发布的类型包。声明不实现业务请求，不冒充 SDK 全部接口，不忽略缺失导入或用 `Any` 绕过检查。维护说明见 [typings/README.md](../repos/tgo-api/typings/README.md)。
- 可选存储 SDK 缺失时仍由构造函数返回原有 `ImportError`。SDK 存在时 `ClientError` 仍是实际异常类，缺失时回退 `Exception`；上传、读取大小上限、关闭、删除、存在检查与 URL 逻辑保持。
- 没有修改旧 MCP 路由、当前工具/插件接口或设备 MCP。旧版独立服务的目录、安装记录和执行回执不能用新工具的数据虚构补齐，兼容范围仍待明确。

660 份 API 运行源码仅上述三个模块变化。完整公开/内部 OpenAPI、574/32 条 HTTP 鉴权依赖、1 条 WebSocket 依赖、89 表和 76 索引与修改前一致；没有模型或数据库迁移变化。

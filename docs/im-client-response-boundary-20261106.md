## 本次修正

1. **按真实结构接收 IM 响应。** 保留既有连接池、代理隔离、请求参数和允许空成功正文的行为；传输边界明确支持 JSON 对象与对象数组。非空乱码、标量或含非法元素的数组返回受控 `502`，不再被当作空成功回执。原 `strict_response` 参数继续接收，非法非空正文不论该参数值均拒绝。
2. **对象回执与数组结果分别核对。** 对象接口不接收数组回执；在线状态和会话同步保留原有数组协议。历史消息、同步和搜索继续执行原有 payload 解码，同时检查嵌套消息结构，避免把任意标量当作消息对象。消息序号只接受非负整数，布尔、字符串、负数等不再作为有效序号返回。
3. **错误正文不进入返回值和日志。** 上游非成功状态继续使用既有 `500` 映射及固定错误说明，只记录状态或异常类别；不复制上游 `msg`、网络异常正文、完整响应或原始解码异常内容。正常业务数据与错误处理分开，不以隐藏日志替代失败状态。
4. **去除完全相同的企微切换重复定义。** `NativeHandbackReceipt` 和 `prepare_native_mode` 的两份定义先按 AST 核对相同，再保留一份；切换条件、请求参数、回执状态和拒绝规则不变。
5. **修正旧测试客户端兼容问题。** 企微私有桥接权限测试在发送请求前因旧 `TestClient` 与当前 HTTP 库不兼容而失败。改用项目已有的 HTTPX ASGI 测试方式，两条原有 `403` 拒绝断言保持。产品鉴权和依赖版本未修改。

没有修改 WuKongIM 服务本体、流式事件名、消息载荷协议或外部平台自动回复范围。

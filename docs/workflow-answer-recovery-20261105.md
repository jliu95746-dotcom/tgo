## 实现

- Workflow 在私有运行行中保存节点原调用名额、范围摘要、期限和加密结果；问题与回答不复制到额度用量记录。新迁移 `0024_workflow_ai_result_cache` 增加两个可空私有字段和清理索引，保留原历史，存在调用回执时阻止直接降级删列。
- 数据与原企业、人员/额度租约、运行、节点、执行快照、工作流版本和调用名额绑定。同一节点只能取得一次名额；相同结果可确认，不能用不同结果或新名额覆盖。
- 保存生产者原始 `AgentExecutionReference`，包括员工配置、岗位政策和业务依据修订。返回前复用现有 AI 执行核验接口，再检查当前工作流归属及人员权限；不新取一个配置引用来授权旧回答。身份缺失、员工/知识或授权变化均停止。
- Workflow 对一次生成请求的超时、服务错误或不完整响应，只进行一次有界原结果读取；找不到、未完成或过期时停止，不重发生成。明确权限拒绝或用户取消不进行恢复。
- 加密使用现有 Cryptography 与密钥环解析机制，独立用途派生。默认 900 秒，可配置 60～86400 秒；每条和每次运行都有容量限制。轮换须保留旧密钥；缺失密钥不尝试其他材料。
- API 自身清理任务每 60 秒分批处理终态或到期结果，保留防止再次执行的标记，删除加密正文；读取时立即拒绝停止/终态运行，不等待清理。关闭应用时取消清理任务并关闭 HTTP 客户端。
- 普通运行记录不返回私有暂存字段。已有工作流输出历史仍按其原保留政策管理，本批的暂存删除不等于删除整份历史。

## 实现及用户可见变化

- 模型配置更新的旧能力 JSON 解析改为捕获普通异常。解析期间出现取消、退出或键盘中断时继续向上传递，不执行本处理器后续的提交、刷新和同步；普通旧数据的回退和正常更新保持。测试不等同于真实 PostgreSQL 取消/回滚验收。
- 知识库下载保留下游错误状态码，公开错误细节改为固定提示，不再返回下游原始 JSON 或正文。下载入口日志不记录下游正文、原始异常或响应头值；意外错误不用字符串格式化异常，并抑制向公开 500 错误附加原异常链。正常二进制内容以及原有 Content-Type、Content-Disposition、Content-Length 转发保持。
- 11 处 ORM 布尔查询改用 SQL 布尔字面值，PostgreSQL 与 SQLite 生成的表达式及参数与原来相同。未改筛选、排序或租户条件。
- 确认后移除四个未使用变量及两个模块级 `foreign` 导入。当前 SQLAlchemy **2.0.43** 的实际解析器提供关联表达式所需名称；新进程中全部 **89** 个映射初始化成功，四组关联 SQL 前后相同。字符串关联机制可参阅 [SQLAlchemy 官方说明](https://docs.sqlalchemy.org/en/20/orm/join_conditions.html)。
- 聊天中的 `get_or_create_visitor` 保留为原服务函数的显式别名，已有调用/测试入口保持；没有增加替代实现或空方法。

本批共 11 份运行源码和 3 份新增测试。222 份模型/Schema 文件的类定义保持；完整公开/内部 OpenAPI、574/32 条 HTTP 鉴权依赖、1 条 WebSocket 依赖、89 表和 76 索引一致。依赖清单、锁文件和其他服务没有变化。公开下载错误信息的变化是本批有意修复，不将其表述为所有返回内容不变。

## 行为修正

| 配置 | 本批候选行为 |
| --- | --- |
| 明确选择非空模型 | 优先使用该模型 |
| 未选模型，或旧配置保存为空白 | 使用供应商当前的非空默认模型 |
| 未选模型，供应商默认也为空 | 不编造 `gpt-4`，不调用 AI，按客服忙闲程度分配 |
| 调用前供应商已停用、软删除、实际删除或不属于当前项目 | 不调用该供应商，继续负载分配 |
| 默认模型在另一事务中更新，本会话还保留旧对象 | 查询使用 `populate_existing()` 刷新后再选择，不能沿用缓存旧值 |

供应商查询同时限制 ID、项目、启用和未删除状态；分配规则也必须属于当前项目。复用 API 自己的供应商记录与现有 AI HTTP 客户端，没有直接读取其他服务数据库。

`model_used` 与本次传给客户端的模型参数一致；没有发起模型调用时，`model_used`、`prompt_used` 保持为空。该字段表示请求时选定的模型，不等同于生成成功或费用确认。没有回填旧历史记录。

原模型响应校验、非法文本拒绝、受控日志和取消传播继续保留。系统提示词、用户提示词、温度、token 上限及公开接口结构没有改变。

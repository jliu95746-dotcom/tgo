# 个人微信本机桥接验证进度

## 目标与边界

- 微信 Windows 4.1.13.65；只读进程内存取得匹配密钥，读取聊天历史和新消息。
- 不 Hook、不注入 DLL、不写微信进程内存、不修改微信源数据库。
- 用户确认首次仅使用文件传输助手并填写回复，不发送。
- 源码：`tools/wechat_local_bridge/`；本地敏感数据：Git 忽略目录 `.tmp/wechat-local-bridge/`。
- 私有运行目录仅当前 Windows 用户及 SYSTEM 可访问；不修改源微信目录权限。

## 已有现场证据

- 本机程序文件版本核对为 4.1.13.65。
- 微信主进程只读扫描：20 个数据库通过 HMAC 密钥校验，归属同一账号。
- 扫描仅申请 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`；未输出密钥或原始内存。
- 取钥算法参考 MIT 项目 TANGandXUE/wcdb-key-tool，核对提交 `79f1b5b92e12c66aa281b4a60a3c478b5f547dfa`。
- 微信独立验证阶段未启动 TGO 后端和 Docker。客服联调阶段的服务状态见接入小节。
- 微信 UI 仅暴露外层渲染窗口，不通过写内存启用辅助功能；RPA 采用视觉锚点定位、普通窗口恢复与键盘输入。

1. 数据库页 HMAC、已提交 WAL 合并、SQLite `integrity_check` 在当前账号的联系人、会话和消息库通过。
2. 文件传输助手初始 20 条历史已读取；原文与导出仅留本机私有目录。
3. 用户从手机发送其他文字后，常驻监听捕获第 21 条消息，正文读取到 1693 个字符；未依赖测试前缀。

## UIA 与窗口适配优化（2026-11-02）

### UIA 实测

- 使用 `comtypes` 直接访问 `CUIAutomation8 / IUIAutomation2`，关闭 `AutoSetFocus`，读取 RawView 和 ControlView；诊断不调用 `SetValue`、`SetFocus` 或 MSAA 动作。

## 运行方式

从项目根目录运行，解释器位于本轮独立运行目录：

```powershell
& '.tmp/wechat-local-bridge/venv/Scripts/python.exe' -m tools.wechat_local_bridge.cli history
& '.tmp/wechat-local-bridge/venv/Scripts/python.exe' -m tools.wechat_local_bridge.cli serve --port 0 --rpa-binding .tmp/wechat-local-bridge/rpa-binding.private.json --max-minutes 30
```

需要重新取钥时，先核对微信主进程 PID 与本人账号目录，再使用 `capture --pid <主进程PID> --account-root <本人账号目录>`。失败或未验证任何密钥时不覆盖旧密钥；更换账号或进程不自动沿用绑定。

窗口适配验收时使用 `http://127.0.0.1:6940`，当时以 `--max-minutes 0` 启动。上面的重新启动命令将打印新结果页地址，监听最多 30 分钟，可点击“停止监听”提前停止。后台的 Python venv 启动器会转交基础 Python 进程，停止时必须同时核对专属模块命令、记录 PID 和监听端口归属。

## 客服系统接入

用户授权文件传输助手作为唯一收发会话，并允许试发。接入使用独立的「微信本机测试」网站渠道和专用访客，沿用渠道绑定的 AI 员工、知识库和客服会话。桥接启动时记录微信与客服的消息位置，从新消息开始同步。文本进入客服 API 后，桥接读取该访客的完整客服回复，再经微信客户端发送。

- 接入调用 `POST /v1/visitors/register`、`POST /v1/chat/completion` 和 `POST /v1/visitors/messages/sync`。请求使用渠道 Key 与当前访客凭据，桥接配置只接受本机回环地址。
- 微信消息编号用来关联客服侧的接收回执。同一账号的手机消息可正常接入。发送之前记录意图，点击之后核对微信数据库新增消息，匹配的出站消息按回执识别。微信同步补齐服务端编号后，同一分库和本地行的出站回执仍能识别，结果未知时暂停联调。
- 已有文本草稿会保留。自动发送要求文件传输助手标题、输入框回读、已启用的发送按钮、窗口位置和焦点均通过检查。每次运行默认试发上限为 3 条，30 分钟到期。`--test-prefix` 可限定测试问题前缀。
- 旧的独立验证模式可用于草稿验收。客服联调配置、访客凭据和账本位于专属私有运行目录。

在客服后台新建专用网站渠道并绑定可用的 AI 员工。取得该渠道 ID 与 API Key 后，在本机交互终端运行绑定命令。Key 通过隐藏输入录入。窗口绑定包含搜索结果锚点时，发送时可自动打开文件传输助手。

```powershell
& '.tmp/wechat-local-bridge/venv/Scripts/python.exe' -m tools.wechat_local_bridge.cli bind-tgo --base-url http://127.0.0.1:18000 --platform-id <专用测试渠道UUID>
& '.tmp/wechat-local-bridge/venv/Scripts/python.exe' -m tools.wechat_local_bridge.cli serve --port 6941 --rpa-binding .tmp/wechat-local-bridge/rpa-binding.private.json --tgo-config .tmp/wechat-local-bridge/tgo.private.json --allow-send --max-sends 3
```

控制页显示客服接入、待发送回复和微信回执，可点击「停止监听」。本机已将发送按钮的图像锚点保存到私有窗口绑定文件。

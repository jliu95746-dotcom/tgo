- 跨服务扫描退出 0 并列出候选引用，实际字段及接口契约不变，没有同步无关服务的排版。PR 摘要脚本退出 1，仅有标题，未计通过；提交范围用实际 Git 差异复核。
- Poetry 保留既有元数据弃用警告；测试保留已有 Pydantic、时间和框架弃用警告，没有借此调整业务或依赖版本。
- 本机最小栈均未运行；新检查确认 Docker Linux engine 管道不存在，未执行正式 CLI/Ego 全栈验收或 Linux 镜像构建。现有本机原生进程/传输夹具和受控 HTTP 测试，不替代真实第三方插件全生命周期、数据库或正式渠道验收。

## 修改与兼容边界

- 28 份 schema 的 776 个非必填 `Field(value, ...)` 改为 `Field(default=value, ...)`。必填 `Field(...)` 保持。使类型检查识别运行时原有默认值，消除子模型默认工厂的错误报错；未增加 lambda 或关闭类型规则。
- Provider 创建接受模型编号或带类型的模型对象，响应仍只返回模型编号。抽取私有连接字段基类，避免不同列表类型覆盖；公共字段保持。
- Visitor 平台参数声明为 `Platform | None`，沿用原有效 AI 模式和超时规则，经原 Pydantic 模型验证结构化数据；保留公开的 `VisitorRegisterResponse` 导入别名。
- 活动与消息 schema 将弃用的 `example` 改为 `examples`；移除确认不用的导入、过时 validator 注释，computed property 只保留对应的 `prop-decorator` 注释。
- 仅调整涉及文件的长度及空白。普通字符串实际值经 AST 比对保持；9 处文档字符串仅调整空白。未改模型/表、迁移、依赖、CI、全局检查规则或消息协议。

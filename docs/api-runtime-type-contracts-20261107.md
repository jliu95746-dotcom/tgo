## 完成内容

- 通用数据服务补齐创建、更新资料的新版/旧版序列化协议，保留创建无参数、更新 `exclude_unset=True` 的调用方式；使用映射字段构造查询，并以 `Session.get` 保持原主键读取与删除行为。支持原筛选、分页、软删除及没有项目/软删除字段时的原回退。
- 无效模型把常量当作 `id` 时，现在拒绝生成查询。隔离 SQLite 对比复现：原函数在该构造下可以把主键 42 的行当作编号 1 的结果取回；新函数受控拒绝。正常映射实体回归通过，不据此宣称已有业务接口曾发生该问题。
- PostgreSQL 权限行锁目标改用映射列；实际原、新函数在全局授权、项目授权和无授权三种情形下，生成的完整 SQL、参数和结果一致。没有减少锁定的表，也不把编译比较当作真实并发锁验收。
- OpenAPI 原有错误响应处理移入 `FastAPI` 子类方法，保留缓存、扩展路由和元数据；方法执行体经接收者改名后与原回调相同，避免动态覆盖方法的类型错误。
- 上手引导明确可空请求体。此前无请求体、JSON null、空对象、空步骤均已实际接受；本批修正对应文档，不改变这些请求的行为。完整 OpenAPI 仅该请求体增加 null 分支，其他接口、鉴权依赖和数据库保持。
- 保留内部用户编号的非字符串兼容、平台同步缺失时间戳的回退和历史对话异常载荷的跳过。安装完成日期继续由原响应模型验证，缺失必填日期仍拒绝，不补造日期。

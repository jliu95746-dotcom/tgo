## 本次行为

1. **HTTP 成功不替代响应校验。** 设备服务的现有接口返回 JSON 对象；客户端检查真实 JSON 值，不再把数组、标量、null、空正文或乱码作为有效对象返回。异常成功正文转成固定的设备服务错误，不带原始正文。
2. **解绑和断开需要明确确认。** 已核对当前设备服务，两种成功响应都包含布尔 `success: true`。客户端只有收到该值才返回成功；缺失、false、数字或字符串等均报告结果未确认，提示刷新设备状态。单次请求没有自动重发；测试不操作真实设备。
3. **设备接口不外露上游错误正文。** 上游 4xx 保留状态码，按状态提供固定说明；不返回原始 `detail`、HTML、任意 JSON 或响应正文。网络和未知异常只记录操作上下文与异常类别，不把异常文字写入日志或 `500` 返回。既有公开 HTTPException/TGOAPIException 的处理保持。
4. **补齐接口与客户端类型。** 使用 JSON 对象、查询参数和请求映射类型，移除客户端业务接口的 Any；为九个原无注解的接口补返回类型，同时显式保持原 `response_model=None`，避免仅因注解改变公开响应定义。
5. **保留已有执行边界。** 项目签名逻辑、五分钟令牌期限、设备范围、管理员要求、策略归属与版本复核、执行记录检查以及调试流内容未修改。签名源文件、请求调用 AST、完整接口和权限依赖另作前后对照。

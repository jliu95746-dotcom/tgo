## 实现

1. 公共响应字典声明准确的 `int | str` 状态键和元数据类型，支持 FastAPI 原有接口；实际状态、描述和错误模型不变，没有使用 `Any` 或忽略规则规避检查。
2. 从现有 `get_authenticated_project` 返回值建立 `AuthenticatedProject` 类型别名，为八个模块的 49 处原依赖参数补注解；默认依赖、缓存和函数执行体保持。公共字典、security 和这八个模块去除类型/导入/文档后，执行 AST 十份全部一致。
3. 插件错误处理标明 `NoReturn`，与原始所有分支都会抛异常的事实相符。已受控的 `HTTPException`、`TGOAPIException` 保留原实例。插件结构化 JSON `detail` 和原 4xx 状态保持；纯文本、缺少 `detail` 或格式异常的 4xx 不再透传整个正文；未知异常不再向调用方返回原始异常文字。
4. 插件 SDK 预期成功对象时验证 JSON 对象，错误数组、标量、空值或非 JSON 受控 502。原 404→`None`、空目录默认值、正常 JSON 内容、请求路径/参数/头和超时继续；没有增加重试。
5. SDK 和端点日志移除响应正文、地址和原始异常，保留状态、操作及异常类型。此处只证明这两个日志入口的专项结果，不代表历史日志或全系统隐私验收完成；正常结构化业务错误详情继续按原约定返回。

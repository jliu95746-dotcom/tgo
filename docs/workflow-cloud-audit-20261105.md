## 已证实的缺口

- AI 接到本次工作流调用后返回 HTTP 403。API、AI、Workflow 及 Worker 均 healthy；四者内部共享密钥配置存在且与 API 一致，尚不能据此断言全部执行权限正确。
- 该测试员工当前停用、独立岗位配置为网页商品咨询；工作流调用契约使用 internal 资料渠道。页面提示“此员工尚未启用，测试前请在员工页处理”。这些是需核对的执行条件，尚未将某一个条件认定为 HTTP 403 的唯一原因。
- 页面仅显示“节点「知识库答疑」（agent）执行失败（RuntimeError），请检查节点配置。”，没有帮助用户区分员工状态、渠道岗位、当前资料和内部执行授权等原因。不能将后台已接受请求或服务 healthy 当作业务测试通过。
- 当前只验证了后台原执行查询；工作流首页运行记录、节点实际输入/输出、完整父子链路、固定发布及恢复仍待继续，不以本次失败代替完成证据。

## 实现范围

- 新增 `plugin_failures.py`，精确匹配可公开提示；未知异常使用固定失败文案。应用错误日志只记录操作类别和异常类型，不记录异常正文或 traceback。
- 安装器的 Git、Go、Python venv/pip、npm 构建失败不再返回 stderr；克隆进度不展示仓库或 ref 原文。真实命令参数不变。
- 安装及启动失败先清理可公开错误，再写入状态和 `last_error`。异常路径仍标记错误，不产生完成事件。
- 升级保留新旧版本文件和配置的切换顺序，继续区分“旧版本恢复并连接”“文件恢复但重启失败”“恢复未确认”“无法停止而保留备份”。新版本已连接但备份清理失败时，继续保留新版本，不误回滚。
- Runtime 的安装/升级 SSE、普通安装、来源解析及更新检查不再回显其捕获的原始异常；既有结构和受控状态码保持。API 本批没有修改运行源码，仅新增跨服务测试。

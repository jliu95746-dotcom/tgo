# 知识库 HTTP 诊断与中断处理（2026-11-07）

本批对应剩余计划 4.2.360，继续 P4/P8 及工程验收。修复知识库 HTTP 入口的原文诊断、校验错误序列化、协议响应头丢失和流式中断处理；原检索、知识治理及内部身份门禁保持。全量 D1～D7、P1～P9、G0～G5 范围不缩减，真实订单/物流暂缓、安卓取消。

## 实现与行为边界

- 请求日志使用声明的路径模板和有限 HTTP 方法，不记录完整 URL、动态路径值、查询参数、客户端 IP 和 User-Agent。未知路径标记为 unmatched，未知方法标记为 OTHER；请求编号、耗时响应头及上下文清理保留。
- HTTP 错误保留状态、错误码和显式公开详情，并恢复此前丢失的 `WWW-Authenticate`、`Retry-After` 等响应头；移除调试打印和日志中的详情原文。
- 校验错误继续返回 422、字段位置及错误类型，不回显 `input`、`ctx`、原始校验器消息等值。常见字段错误提供固定文案。含 ValueError 对象的校验上下文不再引起 JSON 序列化失败、把应有的 422 变成 500。
- 通用 ValueError 保留 400，返回固定公开提示；其他异常保留 500。日志只记录异常类型，不调用异常的 `__str__`，不附带私密异常链。
- 直接传递 ASGI（应用与服务器之间的请求、响应协议）消息，替换原请求日志及身份门禁的 BaseHTTPMiddleware 适配。内部门禁仍只在 SaaS 和计费均启用时保护 `/v1/`，按原令牌校验；原 403 正文、公用路径和非 HTTP 委托保持。
- 响应开始前的未知异常转为统一错误响应；响应开始后记录固定诊断并向服务器传递固定的中断异常，不追加第二份响应或伪造完成。取消信号保持传播，WebSocket/lifespan 不经过 HTTP 错误转换。
- 停用包含原 URL、客户端地址的 Uvicorn 默认访问日志，使用应用已有的结构化请求日志。真实 HTTP 测试显式启用服务器 access_log，验证应用边界仍阻止其记录原值。

范围为上述 HTTP 入口。显式 HTTP 详情仍由业务端点负责提供可公开内容；其他路由内部、后台任务、启动/关闭及 Provider 的日志仍需继续审计，不能据此关闭整个 P8 或宣称所有日志均已验收。

## 实际缺口与实现范围

完整 AI 类型检查发现 `wrap_mcp_authenticate_tool` 调用 `Function.from_callable` 时传入不支持的 `description`。在当前安装的 Agno 中，该方法只接受 callable、name、strict；实际调用会抛出 `TypeError`。`AgentBuilder._build_mcp_tools` 对转换异常记录后跳过，因此需要登录授权的 MCP 工具可能没有进入员工可用工具列表。

本批把鉴权包装独立到 `app/runtime/tools/mcp_authentication.py`，`utils.py` 保留原导出供现有调用者使用。复制原 `Function` 并仅替换 entrypoint，保留 MCP 参数 schema、必填项、描述、确认和人工输入要求、外部执行标记、执行钩子及其他原设置，也不修改原对象。同步和异步 callable 均可包装；缺少 entrypoint 时提前拒绝。

MCP `-32003` 仍转换为原有登录提示，兼容字符串/文本对象及未识别附加数据。其他异常、取消及含取消的异常组原样传播，不以鉴权提示覆盖取消。没有取消原鉴权、租户范围或人工确认，也没有启用新连接、远程员工或任何真实业务操作。

本批没有 API 字段、数据库模型、迁移或 SSE 事件格式变更。影响范围是 AI 工具运行时，API/Web 无运行代码变更；主要入口仍是云端域名，隔离测试不替代正式页面和真实外部系统验收。

## 范围与问题

本批属于 P4 资料接入辅助接口和 P8 安全、日志保护。旧网页预览会按用户输入的网址读取网页并自动跟随跳转，没有核验最终连接地址；完整网址和原始异常还会进入日志或错误说明。隔离回归证明旧实现会尝试访问私有地址，并存在不安全链接和相对图标地址解析问题。

服务端请求伪造（SSRF，即诱导服务器访问内部地址）需要在实际连接入口限制；只对最初的 URL 做文本检查不足以限制跳转或 DNS 地址变化。

## 已完成的行为与边界

1. 请求维持 GET，允许公网 HTTP、HTTPS、合法自定义端口及公网 IPv6。拒绝 URL 账号密码、私有/本机/链路本地/组播等地址，以及混有私有地址、无效地址或过多结果的 DNS 响应。
2. 每次跳转重新核验 DNS，把连接固定到本次已核验的地址，同时保留原 Host、TLS SNI 和证书域名校验。复用现有 Workflow/业务查询的实现模式，没有建立跨服务源码依赖。
3. 正常公网重定向继续支持，最多 5 次；循环跳转、无 Location、非法目标及不安全后续地址受控结束。没有增加重试。
4. 原 10 秒超时改为覆盖 DNS、跳转和读取的整体期限；响应最多 1 MiB，检查声明和实际读取量。读取失败、超限或取消时关闭响应流。请求要求 identity 编码，对仍压缩的响应受控拒绝，避免无界解压。
5. 仅本接口的网页读取使用直连并关闭环境代理，以保持已核验地址的约束；没有调整系统代理、其他客户端或服务器配置。依赖外部代理才能访问的网站仍需单独验证，不自动退回未核验的访问路径。
6. 相对 favicon、Open Graph 图片按最终网页地址解析；仅返回 HTTP/HTTPS 格式的资源链接，不返回 JavaScript、data 或文件链接。本接口不下载这些资源，也不表示已经核验其远端 DNS。
7. 解析结果改为内部明确字段类型；保留原公开响应字段、员工鉴权、正常状态和错误响应结构。失败日志与错误说明不拼接完整 URL、异常原文或上游正文。正常响应中的原输入 `url` 字段继续保留。

## 实际修改与兼容性

本批为 12 份文件：Runtime 8 份源码、3 份新增测试，以及 API 一份现有传输测试。API 运行代码、模型、Schema、数据库迁移、依赖和锁文件没有修改。

- 插件启动时按本次配置和实际子进程环境建立独立保护快照，先处理输出再进入日志缓冲。保护已知配置值、敏感环境变量、凭据参数及其 JSON/URL 编码、常见授权头、邮箱、长电话号码和身份证号；移除终端控制序列。配置、日志及错误字段不进入管理对象的默认表示。
- 输出按 4096 字节读取，每行最多缓冲 16384 字节。超长整行丢弃并保留固定提示，继续读取后续输出；保留正常中文、日期、未以换行结束的普通诊断。读取失败只记录操作和异常类型，取消仍向上传递。
- 每个进程独立计算保护容量，重启不会累计消耗旧配置预算；旧进程尚未读完的输出继续使用它自己的快照。读取历史缓冲时再次保护；历史错误只返回既有公开提示或通用失败提示，不修改数据库原值。
- 插件来源 YAML 的解析和传输失败不再记录 URL、正文或异常原文；仅接受字符串键的对象。非法 source/binary/URL 类型受控拒绝，相关实际接口由意外 500 改为 400；合法 GitHub 来源仍允许可选 binary 为空，正常相对地址和可编辑配置值保持。
- Runtime 全局与私有测试路由共用安全校验错误格式：保留已声明的顶层字段位置、内置错误类型和固定 `msg`，不包含输入、上下文、原文或用户动态键。私有接口补上 OpenAPI 原已声明必填的 `msg`，外层仍为 `detail` 数组；这是实际响应与声明契约的对齐。
- 常规日志配置同时将 httpcore 设为 WARNING，来源读取沿用现有 HTTP 日志保护范围。没有修改插件归属、查询条件、安装升级锁、恢复状态或 SSE 生产协议。

保护已知值和常见格式不代表可以识别任意自由文本、未知个人信息或任意混淆编码。成功读取的可编辑配置没有全局替换为掩码，以免破坏原有编辑和安装用途；其权限和凭据展示仍是后续独立审计项。

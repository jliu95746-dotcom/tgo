## 本批范围与行为

- 文档错误页转义标题与说明中的 HTML 字符，未知服务继续返回 404；远程服务地址缺失直接返回 503，不创建 HTTP 客户端。代理请求仍使用原地址与 10 秒超时，合法 JSON 对象、数组和字符串保持；无效、不可序列化的 JSON 及远程错误统一返回原有 503 提示。日志只记服务名和异常类型，响应不带原始异常及异常链。
- Logo 创建目录纳入存储异常处理，目录或文件写入失败返回固定 500 提示，清理失败文件并保留原有提交边界；读取及替换时分别保存一次路径值。原有项目归属检查、MIME 和大小限制、路径范围检查、公开读取与缓存响应保持。
- 已存储模型密钥无法解密时，Ollama 连接使用空字符串，其他服务继续要求补填密钥；保留服务类型、地址一致性与项目归属校验，不对外调用真实模型。
- 个人微信连接配对在既有功能开关、渠道状态及授权检查后读取 Redis 地址。配置已缺失时返回既有 503 提示，不以空地址建立连接；正常配对逻辑保持。
- 辅助接待提醒缺少消息编号与时间时跳过该条无效记录，继续处理其他有效记录；已有编号优先，缺编号但有时间仍按原规则生成标识。原有查询范围、模式、排序、数量上限保持。
- 文档服务与快速上手常量增加明确类型；快速上手五步的全部值保持。环境配置通过 `BaseSettings` 工厂加载，`SECRET_KEY`、`DATABASE_URL` 仍为必填且校验规则保持。编码和加密工具补上已有空输入行为的类型声明。

本批 9 份运行源码、1 份新增测试；未调整数据库模型、迁移、依赖、检查规则或前端界面。对应配置与安全的工程收敛，不关闭整项业务验收。
